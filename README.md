# Age of Learning — Analytics Case Study

Exploratory analysis of ABCmouse user engagement data across three questions:

1. Is there a significant difference in what users do on Day0 vs Day1?
2. Do users who spend time in Pet Park differ from those who spend time in Mastery Math?
3. How would I set up an A/B test to assess whether Mastery Math on Day0 contributes to Day1 retention?

## Tools
Python, SQL, DuckDB, Pandas, Plotly, Scipy, Sklearn, and some help from Claude

Data file not included for confidentiality reasons.
